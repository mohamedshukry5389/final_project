pd.read_sql_query(
    """
SELECT
    books.book_id,
    books.title,
    COUNT(checkouts.checkout_id) AS checkout_count
FROM
    books
LEFT JOIN
    checkouts ON books.book_id = checkouts.book_id
GROUP BY
    books.book_id, books.title

5- What does a neighborhood's activity look like further back in time?

The neighborhood is 'Nasr City'


code:
pd.read_sql_query("""

SELECT
    members.first_name,
    members.last_name,
    COUNT(checkouts.checkout_id) AS checkout_count
FROM
    members
LEFT JOIN
    checkouts ON members.member_id = checkouts.member_id
WHERE neighborhood LIKE '%Nasr City%'
GROUP BY
    members.member_id
ORDER BY
    checkout_count DESC
LIMIT 10 OFFSET 10;

API VS WEB PAGE


The API makes it easier to find and retrieve information because the website gives you permission to access its data,
making it easier to find and use the information without problems.
However, extracting information directly from the browser is more difficult and takes more time,
and you may find unreliable or inaccurate information.
An example of this is what we did in the project: we had to change the column names and adjust them so that they would match the table without any problems.
